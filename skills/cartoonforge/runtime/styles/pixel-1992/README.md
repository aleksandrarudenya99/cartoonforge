# Pixel 16-bit · early 1990s

Chunky pixels, banded sky, parallax hills, spinning coins, chiptune.

**Lineage:** 16-bit console and arcade game graphics.

## What defines the look
- Everything pixelated on an 8 px grid (`pixelate`)
- Limited palette, banded (not smooth) sky
- Parallax layers, tiled ground
- CRT scanlines

## Sound
- Music: generated `chiptune` at 140 bpm, treated with `none` (see `scripts/lib/audio/`)
- Voice: `bitcrush` treatment, speed 1.0

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No game characters, items or logos from real games

## Legal
Styles, eras and techniques are free to use. Never reproduce characters, logos, titles, signature props or settings of an existing work, even if the user asks for "100% like X" — offer this genre look instead.
