# Soft 3D Feature · 2010s

The family 3D feature look in 2D: soft gradients, rim light, sunny rounded city.

**Lineage:** Genre look of 2010s family 3D features (not any specific film).

## What defines the look
- No outlines; volume from gradients
- Warm key light + cool rim light
- Rounded chunky towers and trees, depth haze
- Full motion (24 drawings/s)

## Sound
- Music: generated `cgi` at 118 bpm, treated with `broadcast` (see `scripts/lib/audio/`)
- Voice: `tv` treatment, speed 1.02

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No characters or districts from existing films

## Legal
Styles, eras and techniques are free to use. Never reproduce characters, logos, titles, signature props or settings of an existing work, even if the user asks for "100% like X" — offer this genre look instead.
