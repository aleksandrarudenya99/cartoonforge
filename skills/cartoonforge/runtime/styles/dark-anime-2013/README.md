# Dark Anime Action · 2010s

Grim action anime: steel palette, red accent, hatched shadows, embers, impact frames.

**Lineage:** Genre look of grim 2010s action anime (not any specific series).

## What defines the look
- Desaturated steel/olive palette + one blood-red accent
- Thick uneven outlines, hatched shadows (`hatch`)
- Storm sky, cliffs, ruins, drifting embers
- Impact frames: speed lines (`speedLines`) + camera shake

## Sound
- Music: generated `epic` at 100 bpm, treated with `cinema` (see `scripts/lib/audio/`)
- Voice: `hero` treatment, speed 1.0

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No giant walls, uniforms, emblems or creatures from existing series
- Don't: Keep characters the user's own
