# Comic Halftone · 1960s pop

Ben-Day dots, heavy outlines, print misregistration, sunburst and POP!

**Lineage:** 1960s comic printing and pop art; its revival in 2018+ stylised animation.

**Also fits:** 2018+ comic-book-styled animated features (halftone + offset print look).

## What defines the look
- Heavy black outlines
- Halftone dot fills (`halftone`)
- Cyan misregistration under every shape (`misregister`)
- Panel border, sunburst rays, onomatopoeia bursts

## Sound
- Music: generated `funk` at 112 bpm, treated with `none` (see `scripts/lib/audio/`)
- Voice: `comic` treatment, speed 1.04

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No smooth gradients — use dots
- Don't: Don't use real comic logos or characters

## Legal
Styles, eras and techniques are free to use. Never reproduce characters, logos, titles, signature props or settings of an existing work, even if the user asks for "100% like X" — offer this genre look instead.
