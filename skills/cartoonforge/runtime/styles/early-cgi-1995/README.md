# Early CGI Feature · 1995–2001

Glossy plastic, hard specular highlights, toy-scale room, crisp shadows.

**Lineage:** Genre look of the first 3D features (not any specific film).

## What defines the look
- No outlines; plastic gloss = base + darker side + white specular
- Simple single key light, crisp drop shadows
- Toy-scale world: wallpaper, floorboards, blocks, ball
- Full motion

## Sound
- Music: generated `cgi` at 116 bpm, treated with `broadcast` (see `scripts/lib/audio/`)
- Voice: `tv` treatment, speed 1.02

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No cowboys, space rangers, ogres or swamps from existing films
