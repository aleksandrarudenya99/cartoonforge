# Round Kids Toon · 2000s

Characters made of circles, rolling green hills, bright friendly colours.

**Lineage:** Genre look of gentle 2000s kids' animation built from circles (not any specific series).

## What defines the look
- Ball-shaped characters (body = head)
- Rolling hills from overlapping circles
- Clean sky gradient, soft thin outline
- Calm bouncy timing on the beat

## Sound
- Music: generated `kids` at 112 bpm, treated with `none` (see `scripts/lib/audio/`)
- Voice: `cartoon` treatment, speed 1.06

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No existing round animal characters or their names
