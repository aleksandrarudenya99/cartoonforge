# TV Anime Adventure · late 1990s–2000s

Bright TV anime: big blue sky, cel shadows, impact flashes and speed lines.

**Lineage:** Genre look of late-90s/2000s TV adventure anime (not any specific series).

## What defines the look
- Clean line, flat colour + one cel-shadow
- Towering cumulus with shaded undersides
- Impact flash stars + radial speed lines
- Snappy holds

## Sound
- Music: generated `adventure` at 132 bpm, treated with `broadcast` (see `scripts/lib/audio/`)
- Voice: `tv` treatment, speed 1.03

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No creatures, headbands, symbols or villages from existing series

## Legal
Styles, eras and techniques are free to use. Never reproduce characters, logos, titles, signature props or settings of an existing work, even if the user asks for "100% like X" — offer this genre look instead.
