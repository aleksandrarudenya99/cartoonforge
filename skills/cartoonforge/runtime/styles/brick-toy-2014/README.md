# Brick Toy Animation · 2010s

A world built from generic plastic bricks: studs, gloss, stepped clouds.

**Lineage:** Genre look of toy-brick animation (generic interlocking bricks).

## What defines the look
- Everything is bricks with studs on top
- Glossy plastic, hard specular glints
- Stepped brick clouds, tile water
- Snapping 12 fps motion

## Sound
- Music: generated `adventure` at 128 bpm, treated with `none` (see `scripts/lib/audio/`)
- Voice: `tv` treatment, speed 1.04

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No brand names or logos, no minifigure designs, no licensed sets
