# Ukiyo-e Action Anime · 2020s

Elemental swirls painted like woodblock prints over endless shifting halls.

**Lineage:** Genre look of 2020s action anime that paints effects like ukiyo-e (not any specific film).

## What defines the look
- Water/flame/wind effects drawn as ukiyo-e curls (`shapes.wave`, `spiral`)
- Endless shifting halls of shoji doors (Escher-like)
- Dark rich palette, brush-weight outlines
- Taiko + flute music

## Sound
- Music: generated `ukiyoe` at 116 bpm, treated with `cinema` (see `scripts/lib/audio/`)
- Voice: `hero` treatment, speed 1.0

- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
