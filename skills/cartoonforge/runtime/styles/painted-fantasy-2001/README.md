# Painted Fantasy Feature · 2000s

Watercolour skies, towering clouds, wind through tall grass, lantern light.

**Lineage:** Genre look of hand-painted Japanese fantasy features (not any specific film or studio).

## What defines the look
- Watercolour paper texture, painted gradients
- Towering summer cumulus, deep greens
- Wind moving grass and leaves together
- Quiet, observant pacing

## Sound
- Music: generated `feature` at 80 bpm, treated with `mist` (see `scripts/lib/audio/`)
- Voice: `airy` treatment, speed 0.96

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No bathhouses, spirits, forest creatures or catbuses from existing films
