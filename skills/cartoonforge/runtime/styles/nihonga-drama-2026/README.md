# Nihonga Drama · 2020s

Mineral-pigment painting, gold-leaf clouds, a crimson sun, smoke and big type.

**Lineage:** Genre look of anime painted like nihonga/ukiyo-e with typographic layers (2020s).

## What defines the look
- Flat mineral colours: azurite, malachite, crimson
- Gold-leaf cloud bands, crimson sun
- Soft drifting smoke as the only non-flat element
- Large outlined typography across the frame

## Sound
- Music: generated `nihonga` at 88 bpm, treated with `cinema` (see `scripts/lib/audio/`)
- Voice: `storyteller` treatment, speed 0.96
