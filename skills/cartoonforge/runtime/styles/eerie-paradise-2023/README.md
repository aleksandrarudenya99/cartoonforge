# Eerie Paradise Anime · 2020s

Poison-bright flowers and misty jungle: a paradise that feels wrong.

**Lineage:** Genre look of 2020s dark-fantasy anime (not any specific series).

## What defines the look
- Lush oversized flowers in pink/gold against deep jungle green
- Pastel misty sky, heavy vignette
- Glowing spores and falling petals
- Beauty/horror contrast

- Music: generated `eerie` at 84 bpm, treated with `mist` (see `scripts/lib/audio/`)
- Voice: `airy` treatment, speed 0.97
