# Soviet Village Cartoon · 1980s

Naive warm drawing, thatched huts, sunflowers, a wattle fence, a big moon.

**Lineage:** Genre look of late-Soviet hand-drawn village shorts (not any specific film).

## What defines the look
- Thin, slightly wobbly naive line
- Warm muted folk palette: ochre, brick, faded green
- Whitewashed thatched hut, sunflowers, wattle fence
- Unhurried deadpan timing

## Sound
- Music: generated `folk` at 90 bpm, treated with `tape` (see `scripts/lib/audio/`)
- Voice: `storyteller` treatment, speed 0.97

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No dogs, wolves or characters from existing films
