# Claymation · 1990s–2000s

Plasticine with thumbprints, chunky cosy sets, 12 poses a second with chatter.

**Lineage:** Genre look of plasticine stop-motion (not any specific film or studio).

## What defines the look
- Clay surface: bumps + thumbprints lit by a key light (`fx.clay`)
- Chunky rounded sets: striped wallpaper, window, rug
- 12 poses/s with set chatter (`fx.chatter`)
- Wide toothy mouths, big eyes

## Sound
- Music: generated `polka` at 108 bpm, treated with `tape` (see `scripts/lib/audio/`)
- Voice: `storyteller` treatment, speed 1.0

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No inventors with dogs, chickens escaping farms or pen-pal tales from existing films

## Legal
Styles, eras and techniques are free to use. Never reproduce characters, logos, titles, signature props or settings of an existing work, even if the user asks for "100% like X" — offer this genre look instead.
