# Classic Musical Feature · 1990s

Hand-drawn epic: painted vistas, giant sunset, god-rays, golden hour.

**Lineage:** Genre look of hand-drawn musical feature films of the 1990s (not any specific film).

## What defines the look
- Fine tapered warm line
- Rich painted backgrounds, epic vistas
- Huge sun, god-rays, golden rim light
- Slow multiplane camera drift, full motion

## Sound
- Music: generated `feature` at 92 bpm, treated with `cinema` (see `scripts/lib/audio/`)
- Voice: `storyteller` treatment, speed 0.98

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No lions on pride rocks, lamps, genies, dragons or castles from existing films

## Legal
Styles, eras and techniques are free to use. Never reproduce characters, logos, titles, signature props or settings of an existing work, even if the user asks for "100% like X" — offer this genre look instead.
