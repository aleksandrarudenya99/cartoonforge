# Magical Sparkle Anime · 1990s

Pastel pinks and lilacs, glitter, ribbons, shimmering transformation skies.

**Lineage:** Genre look of 90s magical-girl TV anime (not any specific series).

## What defines the look
- Pastel gradient night sky
- Sparkles, bubbles, flowing ribbons
- Shimmering colour bands (transformation backdrop)
- Bloom glow

## Sound
- Music: generated `sparkle` at 120 bpm, treated with `vhs` (see `scripts/lib/audio/`)
- Voice: `vhs` treatment, speed 1.04

## Do / don't
- Do draw the user's own characters with this style's `skin` (outline, fills, shading mode).
- Don't: No wands, brooches, tiaras, uniforms or names from existing series
